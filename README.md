# HTML-Only To-Do List

A minimalist, semantic **To-Do List** built strictly using pure HTML and basic inline styling. This project demonstrates how far native browser features can go without relying on JavaScript or external CSS files.

## 🚀 Features

*   **100% Pure HTML:** No JavaScript frameworks, no external stylesheets, and no build steps.
*   **Interactive Checkboxes:** Native browser checkboxes allow you to toggle task completion.
*   **Accessible Labels:** Clickable text labels make it easy to check off tasks on both desktop and mobile devices.
*   **Responsive Layout:** Inline CSS wraps the interface in a clean, centered card that looks good on any screen size.

## 🛠️ Tech Stack

*   **HTML5:** Structured semantic elements (`<main>`, `<fieldset>`, `<legend>`, `<form>`).
*   **CSS3:** Inline styles for layout, spacing, and modern typography.

## 📂 How to Use

1.  **Copy the code:** Copy the HTML code provided in the main project file.
2.  **Create a file:** Create a new file on your computer and name it `index.html`.
3.  **Paste & Save:** Paste the copied code into `index.html` and save the file.
4.  **Launch:** Double-click the `index.html` file to open it instantly in any web browser.

## ⚠️ Important Limitations

Because this project uses **HTML only**:
*   **No Persistent Storage:** Refreshing the page will reset all checked boxes.
*   **Static Add Button:** The "Add" input form mimics a real application UI but will only refresh the page upon submission rather than creating a new list item dynamically.
